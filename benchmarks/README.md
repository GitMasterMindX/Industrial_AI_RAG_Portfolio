# GH.06 — Real Retrieval Benchmark (internal project)

This document describes an **internal** retrieval smoke test on a synthetic fictional-drive corpus. The benchmark runner, dependencies and proprietary retrieval implementation are **not included** in this public portfolio package.

In the full internal project, the benchmark uses BM25, embeddings and Chroma-compatible retrieval and reports Hit@1, Hit@3, mean reciprocal rank (MRR), and elapsed time per query. The two-question smoke test is not a statistically meaningful quality evaluation. No LLM answer generation is tested.

**Public portfolio contents:** selected synthetic scenarios, documentation and experimental reports. There is no runnable GH.06 benchmark in this repository. Historical internal commands are intentionally omitted to avoid implying public reproducibility.

Do not use this material as industrial operating instructions.
